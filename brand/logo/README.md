# Abrolia logo system

The symbol is an open, handwritten lowercase `a` drawn in one continuous line. Its floating coral point suggests a message reaching the other side without turning the mark into a literal chat bubble, globe, or plane.

## Files

- `abrolia-primary-horizontal.svg` — default lockup on light backgrounds.
- `abrolia-secondary-stacked.svg` — centred, compact lockup.
- `abrolia-symbol.svg` — symbol without the wordmark.
- `abrolia-symbol-small.svg` — optically strengthened symbol for 16–32 px use.
- `abrolia-wordmark.svg` — wordmark-only version for unusually narrow placements.
- `abrolia-mono.svg` — single-colour reproduction.
- `abrolia-reversed-on-ink.svg` — reversed lockup on Abrolia Ink.
- `abrolia-logo-sheet.svg` — brand-book overview sheet.

## Core rules

- Keep clear space of at least 1.5 coral-dot diameters on every side. One diameter is the minimum only in constrained UI.
- Use the primary horizontal lockup at 120 px wide or larger on screen.
- Use the standalone symbol at 24 px or larger. Between 16 and 32 px, use the small-size optical version.
- Do not close the handwritten `a`, detach it into multiple strokes, move the coral point, add an arrow, or place the mark inside a badge.
- Primary colours: Cobalt `#2457F5`, Coral `#FFB09F`, Ink `#18222D`, Canvas `#F7FAFC`.
- The editable wordmark uses Avenir Next at weight 700 with tight tracking. Convert the approved wordmark to outlines before sending production artwork to third parties.
