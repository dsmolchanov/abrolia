# Privacy-пакет (Gate −1)

Требование Gate −1 канонического плана
(`thoughts/shared/plans/2026-08-02-family-ops-assistant-mvp.md`, Фаза 0, п. 3):
юридический фундамент существует **до** кода, работающего с реальными данными.

> **Статус: черновик инженера, не юридическое заключение.**
> Пакет закрывает Gate −1 для работы на синтетике и на данных владельца-теста.
> До подключения первой реальной семьи требуется ревью продуктовым владельцем
> и юристом с квалификацией по GDPR (см. «Открытые вопросы»).

## Роли

- **Контролёр** — оператор сервиса (Hermes Cloud, ИП/юрлицо владельца; реквизиты
  подставляются до первой реальной семьи).
- **Субъекты данных** — члены семьи (пользователи) и третьи лица, попадающие в
  содержимое (сотрудники школы, другие родители, дети).
- **Исключение «домашней деятельности»** (ст. 2(2)(c) GDPR) покрывает семью, но
  **не** оператора: сервис коммерческий, обработка — под GDPR в полном объёме.

## Инварианты, на которые опираются все документы

1. Ни одно наружное действие (письмо, сообщение, запись в календарь) не
   исполняется без явного подтверждения человека.
2. Модель не имеет shell, прямой отправки и доступа к чужому household.
3. Данные семьи не используются для обучения моделей (коммерческие условия
   Anthropic API), и не используются для целей, кроме оказания сервиса.
4. Изоляция per-household: отдельный инстанс, отдельный volume, отдельные ключи.
5. Логи не содержат содержимого писем и сообщений — только ID, статусы, размеры.
6. Residency: приложение и БД — EU (Fly `ams`), международные передачи —
   поимённо в [`processors.md`](processors.md); режим `eu-strict` fail-closed.

## Открытые вопросы (до первой реальной семьи)

- [ ] Юридическое лицо/реквизиты контролёра и адрес для запросов субъектов.
- [ ] Ревью юриста: LIA по третьим лицам, позиция по ст. 9, детская политика.
- [ ] Подписанные DPA со всеми процессорами, TIA по передачам в США.
- [ ] Решение по DPO/представителю (ст. 27/37) — вероятно, не требуется в пилоте,
      но должно быть зафиксировано письменно.
- [ ] Формулировка AI-раскрытия (AI Act ст. 50) в исходящих сообщениях.
